# 图标资源目录

请将以下图标文件放入此目录：

- default-avatar.png     — 默认头像 (建议 200x200)
- tab-square.png         — 广场 Tab 图标 (建议 81x81)
- tab-square-active.png  — 广场 Tab 选中图标
- tab-post.png           — 发帖 Tab 图标
- tab-post-active.png    — 发帖 Tab 选中图标
- tab-mine.png           — 我的 Tab 图标
- tab-mine-active.png    — 我的 Tab 选中图标
- icon-like.png          — 点赞图标 (建议 64x64)
- icon-like-active.png   — 点赞选中图标
- icon-comment.png       — 评论图标
- icon-image.png         — 图片图标
- icon-anon.png          — 匿名图标
- icon-anon-active.png   — 匿名选中图标

可在 iconfont.cn 或 flaticon.com 下载免费图标。
